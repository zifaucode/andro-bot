Selamat Datang!

Mari persiapkan BOT-ANDRO dalam beberapa langkah mudah. Pastikan Anda sudah mengaktifkan Wireless Debugging di Developer Options HP Android Anda.

Mode ini memungkinkan bot berjalan langsung di HP ini tanpa perlu komputer.

Keamanan & Akses

Buat kredensial Anda. API Key digunakan oleh Laravel Anda untuk mengirim request ke bot ini.

Harus sama dengan di config Laravel.

Koneksi ADB Loka

Hubungkan bot ke sistem HP Anda. Cek port di Settings -> Developer Options -> Wireless Debugging.

Android 10: biasanya 5555
Android 11+: Cek "IP address & Port" di menu Wireless Debugging

Setup Selesai!

Konfigurasi berhasil disimpan. Saatnya masuk ke dashboard untuk mengontrol bot Anda.
